GNN-Based Harassment
Network Analysis.

Harassment is not always caused by one account. Sometimes, several accounts repeatedly target the same person. This project maps those interactions as a network, studies how accounts are connected, and uses graph learning to highlight patterns that may need closer investigation.

Why analyse a network?

A message can show what was said. A network can also show who repeatedly interacts with whom, which accounts are connected, and whether several accounts target the same person.

The results are indicators for further review, not proof of a person's intent.

Graph components

Nodes

Represent individual user accounts.

Directed edges

Represent observed interactions from the initiating account to the receiving account.

Edge weights

Represent the number of observed interactions for each account pair.

Node features

Include degree, interaction volume, abuse rates, PageRank, betweenness and clustering coefficient.

Louvain algorithm

Partitions the network into groups with dense internal connections. Community membership describes graph structure and is not a harassment label.

Account-level indicators

Degree: number of direct connections. Betweenness: shortest-path brokerage. PageRank: recursive network prominence. Abuse rates summarize available labelled interactions.
